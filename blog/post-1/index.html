【Algorithm】Linear Search 線性查找

By 湯先生 05 November 2024

本篇主要是資料結構與演算法 (JavaScript)的課程筆記。

大家好，我是湯瑪士。身為資管系畢業生，雖然在大學時期與程式無緣，但畢業後透過自學逐漸愛上程式設計。

今天想要和大家分享最基礎的搜尋演算法之一：Linear Search（線性查找）。它的核心重點就是：按順序檢查陣列中的每個元素，直到找到目標值或搜尋完整個陣列。 雖然這是最簡單的搜尋演算法，但是在實務上卻經常被使用。

練習：

  1. 從陣列第一個元素開始
  2. 逐一比對每個元素的目標值
  3. 如果找到匹配的元素，返回該元素的索引
  4. 如果遍歷完整個陣列都沒有找到，返回 -1

JavaScript 實作：

以下是一個簡單的 Linear Search 實作：

function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) return i;
  }
  return -1;
}
